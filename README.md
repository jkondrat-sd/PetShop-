## Các bước để chạy code backend
- Có cài docker desktop
- Chuột phải vào thư mục BackEnd chọn add maven project
- Vào file application.yml ở src/main/resources thay đổi username và password của mysql
- Bật terminal vào folder BackEnd, chạy lệnh docker-compose up --build
